# yasmynbrary-Los-Angeles-Crime-Data-Analysis
Exploratory data analysis of Los Angeles crime data using Python and Pandas.
# Los Angeles Crime Data Analysis

## About the Project
In this project, I analyzed crime data from Los Angeles to find patterns in when and where crimes happen and the ages of the victims.

## Questions
- Which hour has the highest number of crimes?
- Which area has the most crimes at night?
- How many crimes involve victims in different age groups?

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
The project uses `crimes.csv`, which contains information about reported crimes in Los Angeles, including the time, area, crime description, and victim age.

## What I Learned
- Cleaning and preparing data.
- Grouping data and counting values.
- Finding patterns in crime data.
- Using Pandas to answer questions with data.
